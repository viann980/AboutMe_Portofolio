🌐 Personal Portfolio Website

Selamat datang di repositori kode sumber untuk website portofolio pribadi saya. Website ini dirancang untuk menampilkan latar belakang, proyek-proyek yang telah saya kerjakan, keahlian teknis, serta informasi kontak.

📍 Live Demo: https://www.portofolioviann.my.id/

📌 Fitur Utama

Responsive Design: Tampilan yang optimal di berbagai perangkat (Desktop, Tablet, Mobile).

About Me: Informasi ringkas mengenai latar belakang, minat, dan pengalaman.

Projects Showcase: Galeri proyek yang pernah dibuat beserta deskripsi singkat, teknologi yang digunakan, dan tautan terkait.

Skills & Tools: Daftar keahlian teknis dan alat yang dikuasai.

Contact Form / Links: Kemudahan bagi pengunjung untuk menghubungi via email atau media sosial.

🛠️ Teknologi yang Digunakan

Frontend: HTML5, CSS3, JavaScript (atau sesuaikan jika menggunakan React / Next.js / Vue / Tailwind CSS)

Hosting / Deployment: Custom Domain (portofolioviann.my.id)
